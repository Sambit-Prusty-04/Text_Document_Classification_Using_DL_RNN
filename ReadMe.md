# 📝 Text Document Classification Using RNN

## 📌 Overview
This project applies a **Recurrent Neural Network (RNN)** to perform **sentiment analysis** on IMDB movie reviews, classifying them as **Positive** or **Negative**.  
The workflow covers text preprocessing, sequence encoding, model building, evaluation, and prediction.

> ⚠️ **Disclaimer:** This project is for educational purposes only. It is not intended for production use.

---

## 🎯 Objectives
- Preprocess and clean movie review text  
- Convert text into numerical sequences using `TextVectorization`  
- Build a deep learning model with TensorFlow/Keras  
- Evaluate performance using accuracy, loss, and confusion matrix  
- Predict sentiment for unseen reviews  

---

## 🛠️ Technologies Used
- Python  
- Pandas & NumPy  
- TensorFlow & Keras  
- Scikit-learn  
- Matplotlib & Seaborn  

---

## 📂 Workflow
1. Load IMDB dataset  
2. Clean and preprocess text  
3. Split into training and testing sets  
4. Create text encoder and embedding layer  
5. Build and train RNN model  
6. Evaluate with test data  
7. Visualize training performance & confusion matrix  
8. Predict sentiment for new reviews  

---

## 🧠 Model Architecture
- **TextVectorization**  
- **Embedding Layer**  
- **SimpleRNN Layer**  
- **Dense Layers** for binary classification

## 📊 Evaluation
